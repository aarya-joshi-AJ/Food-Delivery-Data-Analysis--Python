Food Delivery Data Analysis Using Python

Project Overview

This project performs Exploratory Data Analysis (EDA) on food delivery order data to identify patterns and insights related to orders, vendor revenue, delivery performance, and customer ratings.

Objectives

- Analyze order distribution across cities.
- Identify top-performing vendors by order value.
- Study delivery time and delivery distance patterns.
- Investigate delivery delays and cancellations.
- Explore monthly order value trends.

Tools & Technologies

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

Dataset

- 3,000 food delivery records.
- Includes order details, cities, vendors, delivery times, order values, weather conditions, and customer ratings.

Key Analysis

- City-wise order distribution.
- Vendor-wise revenue analysis.
- Delivery delays across weather conditions.
- Delivery distance versus delivery time.
- Delivery time category distribution.
- Daily order distribution and monthly order value trends.

Skills Demonstrated

- Data cleaning and preprocessing
- Data type conversion
- Exploratory Data Analysis (EDA)
- Data aggregation and grouping
- Data visualization
- Insight generation
